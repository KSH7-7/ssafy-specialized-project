# whiskeep

위스키를 취미로 하

## 주요 기능
- 기능 1: 설문 응답에 대해 빅데이터 기반으로 위스키를 추천
- 기능 2: OCR을 통해 위스키 라벨지를 인식하여 어떠한 위스키인지 정보 제공
- 기능 3: 텍스트, 이미지와 함께 위스키를 등록하면 위스키별로 피드 형식의 기록 제공
- 기능 4: 마신 위스키를 기록하면 선반 형태에 이미지를 띄워서 위스키병 컬렉션 제공
- 기능 5: 서버에 저장된 위스키 전체 목록 및 향, 맛, 피니쉬 등 다른 사용자들의 평가 등 위스키의 세부 정보 제공
